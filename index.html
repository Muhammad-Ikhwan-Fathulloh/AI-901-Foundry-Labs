Efek Parameter temperature

Ubah slider nilai temperature di bawah untuk melihat perbedaan respons model. Nilai rendah menghasilkan respon kaku dan konsisten (faktual). Nilai tinggi menghasilkan respon kreatif dan bervariasi.

Temperature: 0.0 Deterministik & Faktual
0.0 (Bank/Medis) 0.7 (Umum) 1.5 (Kreatif)
📌 Poin Kritis Ujian: Untuk kepatuhan hukum, perbankan, dan data terstruktur, turunkan parameter temperature mendekati 0.0!

Modul 02: AI Agent Orchestration

Bagaimana Model Memanggil Tools (Function Calling)

Model AI tidak mengeksekusi kode Python sendiri. Model hanya menghasilkan JSON pemanggilan fungsi, lalu aplikasi klien Anda mengeksekusinya.

1

Prompt Pengguna

"Berapa ongkir kirim paket 3 kg ke Surabaya?"

2

LLM Merespons JSON

3

Klien Eksekusi Python

Fungsi lokal berjalan $\rightarrow$ Hasil: Rp 54.000

4

Jawaban Akhir

"Ongkos kirim ke Surabaya adalah Rp 54.000."

Modul 04: Speech AI

Sintesis Suara (TTS) & Tag SSML

SSML (Speech Synthesis Markup Language) adalah format XML resmi untuk mengontrol jeda intonasi dan kecepatan berbicara.

CONTOH STRUKTUR SSML (XML):
<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis" xml:lang="id-ID">
  <voice name="id-ID-ArdiNeural">
    Selamat datang pelanggan!
    <break time="1500ms"/>
    <prosody rate="fast">
      Pesanan Anda sedang kami proses.
    </prosody>
  </voice>
</speak>

Tag <break time="1500ms"/>

Menyisipkan jeda keheningan spesifik (contoh 1.5 detik) sebelum kata kunci dibacakan.

Tag <prosody rate="..." pitch="...">

Mengubah tempo kecepatan suara dan tinggi-rendahnya nada suara.

💡 Catatan Gratis: Modul ini bisa dicoba 100% gratis menggunakan library edge-tts tanpa langganan Azure!

Modul 06: Content Understanding

Alur Pola Asynchronous REST API

Pola ini paling sering diujikan dalam sertifikasi Azure AI: Mengirim file besar tanpa memblokir server.

Langkah 1: POST Dokumen

Klien mengirim file invoice PDF.

Status: HTTP 202 Accepted
Header: Operation-Location
Langkah 2: Polling Berkala

Klien memanggil GET ke URL Operation-Location setiap 3 detik.

Status pekerjaan:
"running" $\rightarrow$ "succeeded"
Langkah 3: Ambil Hasil

Server mengembalikan nilai JSON dari invoice.

Setup Kredensial & API Key

Dua jalur pengujian: menggunakan akun resmi Microsoft Azure atau jalur Alternatif Gratis.

AZ

Jalur Resmi: Microsoft Azure

  1. Buka portal Azure AI Foundry lalu buat Project.
  2. Salin AZURE_AI_PROJECT_ENDPOINT dari menu Project Overview.
  3. Deploy model gpt-4o-mini untuk chat & vision di menu Deployments.
  4. Buat resource Speech Services di Azure Portal untuk mendapatkan AZURE_SPEECH_KEY.
  5. Salin .env.example ke .env lalu isi nilainya.
FREE

Jalur Gratis: Google Gemini & Offline

  1. Dapatkan API Key gratis di Google AI Studio (tanpa kartu kredit).
  2. Di file alternatif/.env, atur AI_PROVIDER=gemini dan masukkan kuncinya.
  3. Untuk opsi 100% Offline Tanpa Key, gunakan model open-source di alternatif/00_free_llm_no_key.py atau pasang Ollama.
  4. Jalankan seluruh modul alternatif tanpa khawatir kuota tagihan!
